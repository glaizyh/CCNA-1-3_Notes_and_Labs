## What's Inside

- **Notes:** module-by-module summaries and reviewers written in Markdown.
- **Labs:** Packet Tracer (`.pkt`) files for configuration and troubleshooting practice.
- **Projects:** larger network designs I built myself.

## Topics Covered

- **CCNA 1:** network fundamentals, IPv4/IPv6 addressing, subnetting, Ethernet, basic switch and router configuration
- **CCNA 2:** VLANs, inter-VLAN routing, STP, EtherChannel, DHCP, FHRP, port security, WLANs
- **CCNA 3:** OSPF, ACLs, NAT, WAN concepts, VPNs, QoS, network automation

## Tools

- [Cisco Packet Tracer](https://www.netacad.com/) for simulations and labs
- Markdown and Git/GitHub for documentation and version control

## How to Use

1. Clone the repo:
```bash
   git clone https://github.com/glaizyh/CCNA-1-3_Notes_and_Projects.git
```
2. Open the notes in any Markdown viewer, or browse them on GitHub.
3. Open `.pkt` files with Cisco Packet Tracer.
